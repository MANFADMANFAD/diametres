# Calculateur de Diamètre Forestier

Une application web mobile simple et autonome pour mesurer les diamètres d'arbres sur le terrain avec reconnaissance vocale.

## 🌳 Caractéristiques

- **Reconnaissance vocale en français** : Dictez vos mesures à voix haute
- **Mobile-friendly** : Fonctionne directement dans le navigateur (Chrome, Safari)
- **Sans installation** : Pas besoin d'APK ou d'app store
- **Calcul instantané** : Moyenne automatique de vos relevés
- **Interface simple** : Optimisée pour l'utilisation sur le terrain

## 📱 Comment l'utiliser

1. Ouvrez le lien suivant sur votre téléphone :
   **https://manfadmanfad.github.io/diametres/**

2. Appuyez sur **"Démarrer l'écoute"**

3. Autorisez l'accès au microphone

4. Dictez vos mesures (ex: "trente-deux", "vingt-cinq", etc.)

5. L'app capture automatiquement les nombres

6. Dites **"Moyenne"** pour calculer le résultat

## ⚙️ Configuration

- **Langue** : Français (fr-FR)
- **Unité** : Centimètres (cm)
- **Navigateurs supportés** : Chrome, Firefox, Safari

## 📝 Notes

- La reconnaissance vocale fonctionne mieux avec une énonciation claire
- Testez d'abord en environnement calme avant utilisation sur le terrain
- Pour les meilleures résultats, utilisez Google Chrome
